# Round 1 submission checklist

Deadline: **9 October 2026, 23:59 IST**

Submission route: organiser Google Form. The link is not available yet. GitHub
Issues are not accepted for Round 1.

## Identity and file

- [ ] Team name is final.
- [ ] Both member names are correct.
- [ ] Contact email is correct and monitored.
- [ ] Every `[TODO]` marker has been removed.
- [ ] Document title and version are present.
- [ ] Final file is Markdown or PDF, as accepted by the form.
- [ ] File opens correctly on another device.

## Required content

- [ ] Problem interpretation is clear.
- [ ] Main hypothesis is testable.
- [ ] Reciprocal hard feasibility is explained.
- [ ] Clarification strategy and daily budget are explained.
- [ ] Pair scoring is explained.
- [ ] Batch allocation and waiting are explained.
- [ ] Missing, declined and delayed data are handled correctly.
- [ ] All three supplied baselines are included in the plan.
- [ ] At least one focused ablation is included.
- [ ] Sparse, cold-start, delayed, shift and drift failures are discussed.
- [ ] Synthetic-data and real-world limitations are stated.

## Evidence checks

- [ ] Proposed work is described as proposed, not completed.
- [ ] Preliminary results have exact commands, seeds and commit IDs.
- [ ] Compared methods use identical seeds and variants.
- [ ] No result was selected only because it looked favourable.
- [ ] No hidden, future or reconstructed information was used.
- [ ] No response is not described as rejection.
- [ ] One-seed organiser examples are not presented as strong evidence.

## Team review

- [ ] Member 1 has reviewed the full note.
- [ ] Member 2 has reviewed the full note.
- [ ] One person checked technical correctness against the problem statement.
- [ ] The other person checked clarity, spelling and form fields.
- [ ] Both members approve the frozen version.

## Submission

- [ ] Confirm the form link from the official submission guide or Discord.
- [ ] Read every form instruction before uploading.
- [ ] Upload the frozen file or provide a fixed document version.
- [ ] Check that the uploaded file/link opens without requesting access.
- [ ] Submit before 23:59 IST on 9 October 2026.
- [ ] Save the Google Form receipt or confirmation screenshot.
- [ ] Record the exact submitted filename, document version and submission time.
- [ ] Do not silently edit the submitted version after the deadline.
