# Round 1 submission pack

This folder contains everything needed to prepare the Round 1 research
submission.

## Main files

| File | Purpose |
|---|---|
| [RESEARCH_NOTE.md](RESEARCH_NOTE.md) | Main document to convert to PDF or submit as Markdown |
| [EXPERIMENT_PLAN.md](EXPERIMENT_PLAN.md) | Exact plan for fair baseline and policy comparisons |
| [FORM_COPY.md](FORM_COPY.md) | Short answers ready to adapt when the Google Form appears |
| [SUBMISSION_CHECKLIST.md](SUBMISSION_CHECKLIST.md) | Final review and submission checklist |

## What to do next

1. Replace every `[TODO]` item in `RESEARCH_NOTE.md` and `FORM_COPY.md`.
2. Agree on the hypothesis and proposed method as a team.
3. Add any preliminary results only after running the documented commands.
4. Let the teammate who did not write a section review it.
5. Freeze the final Markdown or PDF before submission.
6. Submit through the organiser's Google Form by **9 October 2026, 23:59
   IST** and save the receipt.

The Google Form link is not available yet. The organisers will publish it in
their submission guide and Discord. GitHub Issues are not the Round 1 submission
route.
