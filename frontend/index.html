Where CAVIA helps

Development, cold-start, shift and drift

The prototype sometimes changes the selected path productively. On development seed 101, it produced two MSMI outcomes versus greedy’s one.

Where it fails

Sparse geography

On sparse seed 102, targeted clarification missed the only successful path found by greedy. The question-value heuristic needs a sparse-supply safeguard.

What remains unproven

Extra model complexity

Removing uncertainty, feedback weighting, or local pair exchanges did not change the primary score on this seed set.

Constraint-Aware Value-of-Information Allocation

How CAVIA works

An explainable, dependency-free policy. Every soft decision happens after reciprocal hard feasibility.

01

Protect the boundary

Known hard failures remove an edge. Missing hard information blocks it. A soft score never turns an invalid pair into a valid one.

02

Spend questions where they can change the graph

Blocked edges, candidate scarcity, resolvability and waiting time create an observable value-of-information proxy.

03

Score only feasible pairs

Observed soft agreement, scarcity, waiting, mature feedback and uncertainty form the edge value. Missing values never count as agreement.

04

Improve the complete batch

Greedy matching is followed by deterministic two-edge exchanges. The batch remains feasible and non-overlapping.

05

Learn only from mature evidence

Responses, dates and MSMI remain separate. Later-observed profile fields cannot leak into earlier assignments.
